# 房源管理系统 (House Management System Backend)

## 项目简介

基于 Gin 框架的企业级房源管理系统后端服务，现已成功在 Kubernetes 环境中部署并投入生产使用。本系统从零开始设计实现，为房地产中介公司提供完整的房源信息管理解决方案，支持多角色权限管理、细粒度分类筛选、富文本编辑、图片管理以及用户池管理等核心功能。

## 技术栈

- **核心框架**: Gin (Go 1.24)
- **数据库**: PostgreSQL + GORM
- **认证授权**: JWT Token
- **中间件**: CORS、用户认证中间件
- **容器化**: Docker + Docker Compose
- **编排部署**: Kubernetes
- **对象存储**: 阿里云 OSS (图片存储)

## 核心功能

### 1. 房源信息管理
- 房源的增删改查操作
- 多维度房源属性管理（地址、朝向、楼层、价格、装修状况、户型、面积等）
- 富文本内容编辑器支持
- 房源图片管理（支持主图设置）
- 房源多条件组合查询与筛选

### 2. 权限管理系统
- 多角色权限控制（管理员、普通用户）
- 基于 JWT 的用户认证机制
- 细粒度的操作权限控制

### 3. 客户信息管理
- 客户信息的完整生命周期管理
- 客户与房源的关联管理

### 4. 图片处理系统
- 集成阿里云 OSS 对象存储
- 支持图片上传、存储、访问
- 图片与房源的关联管理
- 主图/副图的标记功能

## 项目架构

项目采用标准的 MVC 架构模式，具有清晰的分层设计：

```
house-system-backend/
├── handler/          # 控制层，处理 HTTP 请求
│   ├── admin.go      # 管理员相关接口
│   ├── user.go       # 用户相关接口
│   ├── property.go   # 房源相关接口
│   └── customer.go   # 客户相关接口
├── models/           # 数据模型层
│   ├── property.go   # 房源模型
│   ├── user.go       # 用户模型
│   ├── admin.go      # 管理员模型
│   └── customer.go   # 客户模型
├── middleware/       # 中间件层
│   ├── userMiddle.go # 用户认证中间件
│   └── corsMiddle.go # CORS 中间件
├── route/            # 路由配置
├── Init/             # 初始化配置
├── db/               # 数据库配置
└── utils/            # 工具类（JWT、OSS等）
```

## 技术亮点

1. **容器化部署**: 采用多阶段 Docker 构建，优化镜像体积，支持一键部署
2. **云原生架构**: 在 Kubernetes 集成部署，实现高可用和弹性伸缩
3. **安全性设计**: JWT 认证、密码加密存储、CORS 防护
4. **代码质量**: 清晰的分层架构、良好的错误处理机制、规范的代码风格
5. **可扩展性**: 模块化设计，便于功能扩展和维护
6. **云服务集成**: 集成阿里云 OSS，实现图片资源的高效存储和访问

## 快速开始

### 使用 Docker Compose

```bash
docker-compose up -d
```

### 本地开发

```bash
# 安装依赖
go mod download

# 运行服务
go run main.go
```

服务将在 `http://localhost:8080` 启动

## API 接口

- `/api/v1/property/*` - 房源管理接口
- `/api/v1/user/*` - 用户管理接口
- `/api/v1/admin/*` - 管理员接口
- `/api/v1/customer/*` - 客户管理接口
